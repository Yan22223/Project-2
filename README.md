Assignment Two – Online Analytics Dashboard
Project Overview

This project demonstrates a responsive online analytics dashboard built using HTML, Bootstrap, Chart.js, and Papa Parse. The dashboard visualizes five synthetic datasets created to simulate real-world business data, applying different chart types and layouts for interactive analysis.

Objective

To design and deploy a multi-chart analytics dashboard that reads data from five separate .csv sources, aligns the visualizations within a Bootstrap grid layout, and applies diverse visualization techniques for meaningful insights.

Features

Five synthetic data sources (.csv), each representing a unique dataset.

Five distinct chart types (bar, line, pie, doughnut, and scatter).

Dynamic data loading using Papa Parse for CSV parsing.

Bootstrap column layouts for visually balanced horizontal and vertical alignment.

Fully responsive interface adaptable to mobile and desktop screens.

Industry application: designed for a mock music store analytics use case, tracking sales, genres, streaming trends, customer locations, and price–rating relationships.

Technologies Used

HTML5 / CSS3

Bootstrap 5

Chart.js 4

Papa Parse 5

Visual Studio Code (for development and live preview)
